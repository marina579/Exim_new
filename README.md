# EXIM Contact Enricher - Deployment

This is a clean deployment-ready version of the application.

## Environment Variables Required

- OPENAI_API_KEY
- SERPAPI_API_KEY
- GEMINI_API_KEY (optional)
- ZOHO_CLIENT_ID
- ZOHO_CLIENT_SECRET
- ZOHO_REFRESH_TOKEN
- ZOHO_DATA_CENTER (default: com)
- SECRET_KEY (change from default in production)
- DATABASE_URL (optional, uses SQLite if not set)

## Deploy

This folder is ready to deploy to Railway, Heroku, or any platform supporting Python.

See DEPLOYMENT_GUIDE.md for detailed instructions.
