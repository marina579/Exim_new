=== Environment Variables for Railway ===

Copy these variables and paste into Railway Variables tab.
Replace the placeholder values with your actual API keys!

==================================================

SECRET_KEY=your-secret-key-here-generate-a-random-one
(Generate: python3 -c "import secrets; print(secrets.token_hex(32))")

OPENAI_API_KEY=sk-proj-your-openai-key-here

SERPAPI_API_KEY=your-serpapi-key-here

GEMINI_API_KEY=AIzaSy-your-gemini-key-here

ZOHO_CLIENT_ID=1000.your-zoho-client-id

ZOHO_CLIENT_SECRET=your-zoho-client-secret

ZOHO_REFRESH_TOKEN=1000.your-zoho-refresh-token

ZOHO_DATA_CENTER=com

AUTO_PUSH_TO_ZOHO=true

FLASK_DEBUG=false

==================================================

INSTRUCTIONS:
1. In Railway, go to your service → Variables tab
2. For each variable above:
   - Click "New Variable" or edit the suggested one
   - Copy the variable name (left side of =)
   - Paste your actual value (replace placeholder)
3. Click "Add" or "Save" for each variable
4. Railway will automatically redeploy with new variables

IMPORTANT:
- Replace all placeholder values with your real API keys
- SECRET_KEY: Generate a new random one for production
- Keep these values secret - never commit them to Git
